**Enterprise Engineering | Distributed Systems | High-Volume Order Processing**

An enterprise order management solution within Rakuten's ecosystem, designed to support high-volume order operations and provide visibility into critical order workflows.

- ⚡ Developed using React.js and Spring Boot for enterprise application development.
- 🔄 Integrated Apache Kafka for event-driven communication and asynchronous processing.
- 📊 Supports operational visibility across large-scale order management workflows.
- 🏗️ Built within an ecosystem designed to support high-throughput order processing.

**Tech Stack:** `Java` `Spring Boot` `React.js` `Apache Kafka`

### 02. 🤖 BillAgent — Billing Workflow Automation

**Business Process Automation | Internal Tooling | Full-Stack Development**

An internal automation tool designed to help the billing team eliminate repetitive manual Couchbase document population and streamline operational workflows.

- ⚡ Automates manual Couchbase document-filling tasks performed by the billing team.
- 🗄️ Integrates with Couchbase to simplify document population workflows.
- 🔗 Built with a FastAPI backend and React-based frontend.
- 🎯 Reduces repetitive manual effort and improves operational efficiency.

**Tech Stack:** `Python` `FastAPI` `React.js` `Couchbase`

---

### 03. 🧠 DocuChat — Intelligent Document Q&A

**Generative AI | Retrieval-Augmented Generation | LLM Applications**

An intelligent document conversation platform that enables users to upload documents and interact with their content through natural language queries.

- 📄 Processes uploaded documents into searchable knowledge bases.
- 🔍 Implements Retrieval-Augmented Generation (RAG) to retrieve relevant document context.
- 🧬 Uses embeddings and vector similarity search for semantic document retrieval.
- 💬 Maintains conversational context to support natural follow-up questions.
- 🎯 Generates context-aware answers grounded in retrieved document information.

**Tech Stack:** `Python` `LangChain` `Pinecone` `LLMs` `Embeddings` `RAG`

---

### 04. 🎓 StudyNotion — Full-Stack EdTech Platform

**Full-Stack Engineering | EdTech | Application Architecture**

A comprehensive EdTech platform designed to connect students and instructors through an integrated online learning ecosystem.

- 👨‍🏫 Instructor workflows for creating, managing and publishing courses.
- 🎓 Student workflows for discovering courses and accessing learning content.
- 🔐 Authentication and role-based access control for different user types.
- 📚 Course management and structured learning workflows.
- 🏗️ End-to-end application architecture integrating frontend, backend and database layers.

**Tech Stack:** `MongoDB` `Express.js` `React.js` `Node.js` `JWT`
