An AI-powered document intelligence application that allows users to interact with their documents through natural language conversations.

- 📄 Upload and process documents to create a searchable knowledge base.

- 🧬 Leverages embeddings and vector similarity search for semantic retrieval.
- 💬 Generates context-aware answers grounded in retrieved document content.
- 🎯 Makes document exploration and information retrieval more intuitive.

**Tech:** `Python` `LangChain` `LLMs` `Embeddings` `Vector Database` `RAG`
